# Style maison en pixel — où il vit

- **Règles** : `../RENDU.md` (c'est lui qui décide). `STYLE.md` ici est la traduction technique de ces règles, en anglais, au format que l'outil Lemo sait lire.
- **Code** (source de vérité) dans `code/` : le moteur pixel (`px.js`), la police avec accents (`font.js`), les décors et personnages (`art.js`). Les mêmes personnages servent aussi au HD-2D (`../style-hd2d/`).
- **Nouvel épisode** : partir du dossier `05-rendu/film/` du dernier épisode terminé du même format (liste à jour : `MEMOIRE.md` §5). Short 9:16 : `fr/episodes/S001-guerre-emeus/05-rendu/film/` ; longue 16:9 (pixel 320×180 ×6, décors HD-2D, pixel et HD-2D assemblés) : `fr/episodes/L001-cheval-hans/05-rendu/film/`.
- Pour que l'outil Lemo le trouve, ce dossier est copié dans `~/lemo-my-styles/nan-serieux-pixel/` (voir `~/agence-video/INSTALLATION.md` §5). Si on change le style, on le change **ici**, puis on recopie.
