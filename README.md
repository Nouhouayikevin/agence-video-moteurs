# Moteurs de l'agence « Nan, sérieux ?! » / « Hold Up, Really?! »

La partie publique de l'agence : ce qui n'a rien de secret, pour que les machines de calcul (Google Colab) la téléchargent en quelques secondes au lieu de la recevoir du PC.

- `outils/` : les scripts de production (rendu, atelier Google, contrôles, finition). Chaque outil répond à `--help`.
- `sons/` : la banque de bruitages, enregistrements CC0 (auteurs et liens : `sons/LICENCES.md`).
- `style-pixel/`, `style-hd2d/` : le code des deux styles d'image. Les moteurs repris de Lemo-Opuscar sont sous licence MIT (voir leurs en-têtes).

Ce dépôt est un sous-module du dépôt privé de l'agence (dossier `moteurs/`) ; les épisodes, les scripts des vidéos, la voix et les règles de travail n'y sont pas.
